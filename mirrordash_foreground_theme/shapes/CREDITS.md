# Where the shapes come from

Each shape is one SVG file here, drawn in whatever colour the theme gives it (the files carry no fill of their
own). Swap a file to change a shape; its name is what `themes.py` uses.

| Files | Source | License |
| :--- | :--- | :--- |
| `ghost`, `leaf`, `acorn`, `heart`, `flower`, `tulip`, `butterfly`, `feather`, `egg`, `star`, `balloon`, `drop` | [Phosphor Icons](https://phosphoricons.com), fill weight | MIT, below |
| `lantern`, `ghost-flying`, `maple-leaf`, `snowflake`, `crystal` | [Lorc](https://lorcblog.blogspot.com) on [game-icons.net](https://game-icons.net) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| `pumpkin`, `oak-leaf` | [Delapouite](https://delapouite.com) on [game-icons.net](https://game-icons.net) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| `bat` | Skoll on [game-icons.net](https://game-icons.net) | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) |
| `dot`, `simple-flake`, `simple-heart`, `sparkle`, `twinkle`, `petal`, `blossom`, `birch-leaf`, `daisy`, `grass`, `confetti`, `streamer`, `rain`, `drizzle` | Drawn for this module | The module's license |

The game-icons.net files are changed: their black background square and white fill are removed.
